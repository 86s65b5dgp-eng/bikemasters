# Bike Masters Website

GitHub Pages-ready static website for Bike Masters, Cairo, Egypt.

## Structure

- `index.html` — main page
- `assets/` — all local images/fonts extracted from the original site
- `css/style.css` — site styles
- `js/script.js` — site JavaScript
- `.nojekyll` — GitHub Pages static-site marker
- `.gitignore` — Git ignore rules

## GitHub Pages

Upload **everything in this folder** to the root of your GitHub repository.

Then:

1. Open **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Select your main branch and **`/ (root)`**.
4. Save.

The site will be available at your GitHub Pages URL.

## Important

Do not upload only `index.html`. The `assets`, `css`, and `js` folders are required.
